# Design Guidelines

## Visual reference
Use `Portfolio M.Wail Irsyad.pdf` as the primary reference when it is available. Verify all text and facts against the original document.

## Mood
Dark, minimalist, dramatic, theatrical, and editorial. Performance photography should be the main visual focus. Avoid generic SaaS or template-like styling.

## Suggested palette
- Main background: `#1D1F1F`
- Header/elevated surface: `#292929`
- Secondary surface: `#242626`
- Primary text: `#F4F4F2`
- Muted text: `#B8B8B5`
- Border: `#454747`

Use accent colors sparingly and only where supported by the reference design.

## Typography
- Condensed display type for large headings.
- Clean, readable sans-serif for body text and controls.
- Strong hierarchy and generous reading widths.
- Keep long body copy readable; reserve all-caps for short labels.

## Layout and content
- Spacious editorial composition and restrained separators.
- Large performance photographs with preserved aspect ratios.
- Group photos by event/project and year where verified.
- Keep Research Papers as a separate section/container.
- Navigation: Home, About Me, My Works dropdown, Contact.
- Contact: verified Instagram, TikTok, and WhatsApp links.
- Footer: thank-you message and copyright.

## Responsive/accessibility
- Mobile-first layout; do not merely shrink desktop.
- Keyboard-accessible dropdown and mobile navigation.
- Visible focus states and semantic elements.
- Meaningful alt text for content images.
- Reduced-motion support.
- Touch-friendly controls and no horizontal overflow.

## Assets
Use only owner-provided or owner-approved assets. Never stretch photos or fabricate captions, event dates, credits, or personal details. Use graceful placeholders until real assets are supplied.
